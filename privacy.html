Privacy policy

YT Report. Last updated October 24, 2026.

Data we access

With the channel owner’s permission, YT Report uses the YouTube Data API and YouTube Analytics API with read-only access to the owner’s own channel. This includes channel statistics, video titles and statistics, and analytics such as views, watch time, subscribers gained or lost, and traffic sources.

How we use it

The data is used only to create a daily summary report that is sent to the channel owner’s private Discord channel. YT Report does not modify, upload or delete anything on YouTube.

Storage and sharing

  • YouTube data is processed when the report runs and is not stored in a database.
  • The OAuth token is kept in encrypted GitHub Actions secrets controlled by the channel owner.
  • Data is never sold, shared with third parties, or used for advertising.

Revoking access

You can remove YT Report’s access at any time from your Google Account permissions page.

Third-party terms

YT Report uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
